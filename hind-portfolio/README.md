# معرض أعمال هند المليفي — Hind Almolify Portfolio

موقع ثابت (Static Website) بدون أي أدوات بناء: HTML + CSS + JavaScript فقط، يدعم اللغتين العربية والإنجليزية (RTL / LTR).

## هيكل المشروع

```
hind-portfolio/
├── index.html          ← هيكل الصفحة ومحتواها (الأقسام، النصوص، الروابط)
├── style.css           ← كل التنسيقات (الألوان، الخطوط، التخطيط، الجوال)
├── script.js           ← التفاعلات: نوافذ المشاريع، الفلاتر، القائمة، تبديل اللغة، الشهادات
└── assets/
    ├── images/         ← الشعار وصور المشاريع وصورة الجائزة
    ├── certificates/   ← صور الشهادات
    └── cv/             ← السيرة الذاتية (PDF)
```

## تشغيل الموقع محليًا

**الطريقة الأسهل (Visual Studio Code):**
1. افتحي مجلد المشروع من VS Code: `File ← Open Folder`.
2. ثبّتي إضافة **Live Server** (من قسم Extensions).
3. كليك يمين على `index.html` ← **Open with Live Server**. أي تعديل تحفظينه ينعكس مباشرة في المتصفح.

**بدون إضافات:** افتحي الطرفية داخل المجلد وشغّلي:
```bash
python -m http.server 5500
```
ثم افتحي `http://localhost:5500` في المتصفح. (فتح `index.html` بالضغط المزدوج يعمل أيضًا لأن كل المسارات نسبية.)

> الخطوط تُحمَّل من Google Fonts، فتحتاجين اتصال إنترنت لتظهر بشكلها الصحيح.

## كيف أعدّل؟

| أريد تعديل… | أين؟ |
|---|---|
| الألوان | أول `style.css` داخل `:root` (`--red` و`--bg` و`--paper` و`--ink` …) |
| الخطوط | أول `style.css`: سطر `@import` والمتغيران `--display` و`--body`. للعربي: `.arabic` في قسم Arabic |
| نص في الصفحة | `index.html` (ابحثي عن النص الإنجليزي) |
| ترجمة نص | `script.js` ← `translations`: **المفتاح هو النص الإنجليزي بالضبط** والقيمة هي العربي |
| بيانات نافذة مشروع | `script.js` ← `projects` (العنوان، الوصف، النقاط، الوسوم، الصور) |
| إضافة مشروع جديد | أنسخي بطاقة `<article class="project-card">` في `index.html` وغيّري `data-project`، وأضيفي مدخلًا بنفس المفتاح في `projects`، وترجمات النصوص في `translations` |
| صورة أو شهادة | استبدلي الملف داخل `assets/` بنفس الاسم، أو غيّري المسار في `index.html` (`src` أو `data-cert-src`) |
| السيرة الذاتية | استبدلي `assets/cv/Hind_Almolify_CV.pdf` بنفس الاسم |
| الإيميل والروابط | قسم `contact` في `index.html` |

**مهم:** إذا غيّرتِ نصًا إنجليزيًا في `index.html` أو في `projects`، غيّري المفتاح المقابل له في `translations` بنفس الحرف، وإلا سيظهر هذا النص بالإنجليزي عند تبديل اللغة للعربي.

## النشر على Vercel

الموقع ثابت ولا يحتاج إعدادات خاصة.

**الطريقة 1 — عبر GitHub (الأفضل لأن كل تعديل يُنشر تلقائيًا):**
1. أنشئي مستودعًا على GitHub وارفعي محتوى المجلد (يكون `index.html` في جذر المستودع).
2. ادخلي [vercel.com](https://vercel.com) ← **Add New… ← Project** ← اختاري المستودع ← **Import**.
3. اتركي **Framework Preset = Other**، وفضّي خانتي Build Command وOutput Directory، ثم **Deploy**.
4. بعد دقيقة يظهر رابط الموقع. كل `git push` لاحق يحدّث الموقع تلقائيًا.

**الطريقة 2 — عبر الطرفية:**
```bash
npm i -g vercel
cd hind-portfolio
vercel          # أول نشر (تجريبي)
vercel --prod   # النشر النهائي
```

**ملاحظة:** خوادم Vercel تفرّق بين الحروف الكبيرة والصغيرة في أسماء الملفات (`Logo.png` ≠ `logo.png`)، فحافظي على تطابق الأسماء في `index.html` و`script.js` مع ملفات `assets/`.
