# معرض أعمال هند المليفي — Hind Almolify Portfolio

موقع ثابت (Static Website) بدون أي أدوات بناء: HTML + CSS + JavaScript فقط، يدعم اللغتين العربية والإنجليزية (RTL / LTR).

## هيكل المشروع

```
hind-portfolio/
├── index.html          ← هيكل الصفحة ومحتواها (الأقسام، النصوص، الروابط)
├── style.css           ← كل التنسيقات (الألوان، الخطوط، التخطيط، الجوال)
├── script.js           ← التفاعلات: نوافذ المشاريع، الفلاتر، القائمة، تبديل اللغة، الشهادات
└── assets/
    ├── images/         ← الشعار وصور المشاريع وصورة الجائزة
    ├── certificates/   ← صور الشهادات
    └── cv/             ← السيرة الذاتية (PDF)
```
